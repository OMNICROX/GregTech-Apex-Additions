# Apex Guide

In-game guidebook mod for Apex Ascension (Minecraft 1.20.1, Forge).

- Engine: fork of [GuideME](https://github.com/AppliedEnergistics/GuideME) 20.1 (LGPL-3.0), relocated to `com.omnicrox.apexguide`.
- UI: ported from [GuideNH](https://github.com/GTNewHorizons/GuideNH) (LGPL-3.0) by HFstudio.
- Bundled (shaded, relocated): Apache Lucene (Apache-2.0), SnakeYAML (Apache-2.0), directory-watcher (Apache-2.0).
