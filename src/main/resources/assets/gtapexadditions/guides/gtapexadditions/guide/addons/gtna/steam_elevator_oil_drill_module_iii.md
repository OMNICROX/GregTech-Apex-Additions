# Steam Oil Drill Module III

<Multiblock id="gtna:steam_elevator_oil_drill_module_iii" />

**From:** GTNA

## What it does

* Elite steam oil extraction.
* Adds fluid drill module to the Steam Stairway
* Extracts all underground fluid types in the current dimension.
* Randomly selects up to 3 types of fluids.
* Each extraction may yield 1000~4000L.
* Base cycle time: 400 ticks
