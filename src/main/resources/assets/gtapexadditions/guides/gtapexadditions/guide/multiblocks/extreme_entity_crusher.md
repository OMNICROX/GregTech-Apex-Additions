# Extreme Entity Crusher

<Multiblock id="gtapexadditions:extreme_entity_crusher" />

**Tier:** MV · **Kind:** Farming · **From:** KubaTech (GTNH)

A mob farm. Put a spawn egg or a Hostile Neural Networks data model in an input bus (not used up) and a sword (for looting) if you like: every cycle rolls the mob's loot many times in parallel. Power scales with the mob's health; bosses are refused. A data model's tier adds bonus loot rolls. Hostile mobs can roll as infernal (sigils raise the odds).

## Building it

In the 3D view, left drag rotates, the scroll wheel zooms and right or middle drag pans; right-click a block to see what
that spot accepts. The buttons beside it zoom, reset the view, switch between shapes, show where hatches can go and
list every block you need; the sliders under it pick a tier or show one layer at a time. The
[Structure Upgrader](../items/structure-upgrader.md) builds it for you.
