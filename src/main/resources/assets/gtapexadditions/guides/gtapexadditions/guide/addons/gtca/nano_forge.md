# Nano Forge

<Multiblock id="gtca:nano_forge" />

**From:** GTCA

**Runs:** Nano Forge

## What it does

* Machine Type: Nanite Fabricator
* Requires insane amounts of power to create nanites
* Each tier requires some structural changes
* Machine tier depends on the Nanite in any input bus (GTNA: no controller slot)
* Carbon → T1, Neutronium → T2, Transcendent Metal → T3; the nanite is never consumed
* Tier 4 has additional mechanics (not ported yet)
* Performs perfect overclocks on lower-tier recipes
