# Library of Ruina

<Row>
  <BlockImage id="gtapexadditions:library_of_ruina" scale="3" />
</Row>

**Tier:** IV · **Kind:** Farming · **From:** GT-Not-Leisure

Makes Twilight Forest boss loot in bulk. Built with the Twilight bosses' trophies, so you explore the Twilight Forest at HV and harvest it at IV.

## Building it

Press **U** on the controller in JEI for the 3D structure (layers, tiers, hatch spots, block counts), or use the
[Structure Upgrader](../items/structure-upgrader.md) to place it.
