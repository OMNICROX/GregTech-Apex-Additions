# Cactus Wonder

<Multiblock id="gtna:steam_cactus_wonder" />

**From:** GTNA

**Runs:** Cactus Wonder

## What it does

* Main Function: cactus-fueled steam generator.
* Steam per fuel (GTNL values): coal/charcoal 8000 mB, their blocks 90000 mB, coke 16000 mB, coke block 180000 mB.
* Burns cactus-era carbon fuels and returns their value as steam blessings.
* Requires fully grown cacti on the sand floor to form.
