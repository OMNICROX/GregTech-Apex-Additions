# Thermal Power Pump

<Multiblock id="gtna:thermal_power_pump" />

**From:** GTNA

## What it does

* Main Function: Condenses steam back into water using the ambient biome.
* Oceans and rivers produce the most, the Nether produces nothing; rain boosts the output by 50%.
