# Steam Monster Repellator Module III

<Multiblock id="gtna:steam_elevator_monster_repellent_module_iii" />

**From:** GTNA

## What it does

* This machine makes monsters alert and run away on their own.
* Adds mob repellent module to the Steam Stairway
* Creates a force field to prevent monster spawns
* Only prevents spawns while the machine is running
* Effective range: 256
