# Rocket Large Turbine

<Multiblock id="gtna:rocket_large_turbine" />

**From:** GTNA

**Runs:** Rocket Engine

## What it does

* Main Function: An EV rocket turbine that burns rocket fuel and converts rotor power into EU.
* Base production: 5120 EU/t. An installed rotor is required; output scales with the Rotor Holder.
* Each Rotor Holder tier above EV adds 10% efficiency and doubles the output. The rocket engine module adds 2x output, +20% efficiency and a 2x rotor damage multiplier.
* High-Speed Mode multiplies output by 3 but wears the rotor 10x faster. Only GTCEu Rocket Fuel is ported; GTO's other rocket fuels are not.
