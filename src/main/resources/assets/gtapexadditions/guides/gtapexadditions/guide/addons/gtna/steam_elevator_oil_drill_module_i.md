# Steam Oil Drill Module I

<Multiblock id="gtna:steam_elevator_oil_drill_module_i" />

**From:** GTNA

## What it does

* Extracts oil with steam power.
* Adds fluid drill module to the Steam Stairway
* Extracts all underground fluid types in the current dimension.
* Randomly selects up to 1 types of fluids.
* Each extraction may yield 250~1000L.
* Base cycle time: 1200 ticks
