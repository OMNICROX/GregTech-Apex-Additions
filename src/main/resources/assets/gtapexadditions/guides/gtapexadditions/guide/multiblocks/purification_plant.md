# Water Purification Plant

<Row>
  <BlockImage id="gtapexadditions:purification_plant" scale="3" />
</Row>

**Tier:** UV · **Kind:** Processing · **From:** GT5-Unofficial

Main controller for the eight purification units (clarifier, ozonation, flocculation, pH adjustment, plasma heater, UV treatment, degasser, baryonic perfection). Every unit within 32 blocks links to it; each makes the next grade of purified water.

## Building it

Press **U** on the controller in JEI for the 3D structure (layers, tiers, hatch spots, block counts), or use the
[Structure Upgrader](../items/structure-upgrader.md) to place it.
