# Fishing Ground

<Multiblock id="gtna:fishing_ground" />

**From:** GTNA

**Runs:** Fishing Ground

## What it does

* Main Function: Automatically fishes with bait in a water-filled structure.
* Like eating fish?
* The AFFL-200 intelligent large fishing farm is a regular on the GregTech cuisine series.
* Its powerful intelligent breeding system brings powerful productivity.
* It can meet the entire branch office's aquatic food needs.
* Set the circuit to enable automatic fishing:
* Circuit 1: random fishing.
* Circuit 2: catch fish.
* Circuit 3: catch junk.
* Circuit 4: catch treasure.

> Like eating fish? The AFFL-200 fishing farm is a regular in GregTech cuisine. Its intelligent breeding system delivers remarkable output. It feeds an entire branch office with aquatic food.
