# Mega Distillation Tower

<Row>
  <BlockImage id="gtapexadditions:mega_distillation_tower" scale="3" />
</Row>

**Tier:** ZPM · **Kind:** Processing · **From:** GTNH

Distillation with up to 256 parallels. One fluid output hatch per layer, 2 to 13 layers (it grows in stages).

## Building it

Press **U** on the controller in JEI for the 3D structure (layers, tiers, hatch spots, block counts), or use the
[Structure Upgrader](../items/structure-upgrader.md) to place it.
