# Large Greenhouse

<Multiblock id="gtna:large_greenhouse" />

**From:** GTNA

**Runs:** Greenhouse, Tree Growth Simulator

## What it does

* Main Function: Grows crops and trees in two selectable recipe modes.
* Running Requirements: Can cultivate trees and general crops.
* Can operate without sunlight.
* Tree recipes retain the sapling and use water; fertilizer speeds growth.
