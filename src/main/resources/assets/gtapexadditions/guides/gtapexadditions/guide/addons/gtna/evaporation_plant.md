# Evaporation Plant

<Multiblock id="gtna:evaporation_plant" />

**From:** GTNA

**Runs:** Evaporation

## What it does

* Main Function: Evaporates brine and other fluids in a tall processing tower.
* The stainless tower accepts up to 5 repeated evaporation stages.
* Base: exactly one non-steam fluid input hatch (any tier) and 1–2 energy input hatches. Each tower stage accepts one fluid output hatch.
* Auxiliary Module: Titanium tower enables Parallel and Accelerate hatches.
