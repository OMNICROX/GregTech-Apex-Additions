# Steam-Powered Apiary Module

<Multiblock id="gtna:steam_elevator_apiary_module" />

**From:** GTNA

## What it does

* High pressure makes the bees work harder and more efficiently.
* Adds apiary module to the Steam Stairway
* The bees' (ideal?) home
* Fixed operating time: 300 seconds
* Each overclock doubles the capacity, power ×4
* Base amount: 8
