# Laser Meteor Miner

<Row>
  <BlockImage id="gtapexadditions:laser_meteor_miner" scale="3" />
</Row>

**Tier:** LuV · **Kind:** Processing · **From:** Twist Space Technology

Mines a meteor (or anything) far above it with a laser. Tier 1 mines one block, tier 2 a row, tier 3 a layer. A Botania Terra Shatterer in the input bus gives fortune.

## Building it

Press **U** on the controller in JEI for the 3D structure (layers, tiers, hatch spots, block counts), or use the
[Structure Upgrader](../items/structure-upgrader.md) to place it.
