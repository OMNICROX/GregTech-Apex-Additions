# Lightning Spire

<Row>
  <BlockImage id="gtapexadditions:lightning_spire" scale="3" />
</Row>

**Tier:** LuV · **Kind:** Power · **From:** Apex

Holds up to 512 Spire Lightning Rods (feed them through an input bus). Every 12.8 s each rod adds 28,000,000 EU to its buffer, which drains through dynamo hatches.

## Building it

Press **U** on the controller in JEI for the 3D structure (layers, tiers, hatch spots, block counts), or use the
[Structure Upgrader](../items/structure-upgrader.md) to place it.
