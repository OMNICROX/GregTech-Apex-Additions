# Steam Monster Repellator Module I

<Multiblock id="gtna:steam_elevator_monster_repellent_module_i" />

**From:** GTNA

## What it does

* It drives away monsters with loud noise.
* Adds mob repellent module to the Steam Stairway
* Creates a force field to prevent monster spawns
* Only prevents spawns while the machine is running
* Effective range: 64
