# Singularity Data Hub

<Row>
  <BlockImage id="gtapexadditions:singularity_data_hub" scale="3" />
</Row>

**Tier:** UHV · **Kind:** Automation · **From:** GT-Not-Leisure

Bulk item storage on your AE2 network. Its vault survives being broken (saved with the controller). Runs on wireless power if it has no energy hatch.

## Building it

Press **U** on the controller in JEI for the 3D structure (layers, tiers, hatch spots, block counts), or use the
[Structure Upgrader](../items/structure-upgrader.md) to place it.
