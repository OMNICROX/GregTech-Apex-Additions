# Steam Monster Repellator Module II

<Multiblock id="gtna:steam_elevator_monster_repellent_module_ii" />

**From:** GTNA

## What it does

* You can’t hear it, but the monsters hear it loud and clear.
* Adds mob repellent module to the Steam Stairway
* Creates a force field to prevent monster spawns
* Only prevents spawns while the machine is running
* Effective range: 128
