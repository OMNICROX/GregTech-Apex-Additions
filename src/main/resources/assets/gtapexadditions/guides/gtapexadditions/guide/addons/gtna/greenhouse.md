# Greenhouse

<Multiblock id="gtna:greenhouse" />

**From:** GTNA

**Runs:** Greenhouse

## What it does

* Main Function: Grows crops from a retained seed or plant, water and optional fertilizer.
* Running Requirements: Requires sunlight to operate.
* Insufficient sunlight slows growth; no sunlight stops it.
* Use Rich Soil or Mud in the planting beds.
