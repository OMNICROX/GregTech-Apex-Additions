# Steam Oil Drill Module II

<Multiblock id="gtna:steam_elevator_oil_drill_module_ii" />

**From:** GTNA

## What it does

* Advanced steam oil extraction.
* Adds fluid drill module to the Steam Stairway
* Extracts all underground fluid types in the current dimension.
* Randomly selects up to 2 types of fluids.
* Each extraction may yield 500~2000L.
* Base cycle time: 600 ticks
