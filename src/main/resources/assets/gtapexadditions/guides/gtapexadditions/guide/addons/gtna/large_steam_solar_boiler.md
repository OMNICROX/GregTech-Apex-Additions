# Large Steam Solar Boiler

<Multiblock id="gtna:large_steam_solar_boiler" />

**From:** GTNA

## What it does

* Main Function: Expandable solar steam field using solar boiling cells.
* Structure expands backward and sideways as long as cells remain sunlit.
* Steam Output scales with the number of sunlit cells.
* Structure: starts at 5x1x5 and expands horizontally.
