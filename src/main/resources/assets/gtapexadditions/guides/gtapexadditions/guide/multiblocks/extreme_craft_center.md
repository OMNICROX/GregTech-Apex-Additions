# Extreme Craft Center

<Row>
  <BlockImage id="gtapexadditions:extreme_craft_center" scale="3" />
</Row>

**Tier:** IV · **Kind:** Automation · **From:** Twist Space Technology

An ME crafting provider: crafting patterns run inside it with pattern magnification, so it acts like a huge set of molecular assemblers on your AE2 network.

## Building it

Press **U** on the controller in JEI for the 3D structure (layers, tiers, hatch spots, block counts), or use the
[Structure Upgrader](../items/structure-upgrader.md) to place it.
