# Liquefaction Furnace

<Multiblock id="gtna:liquefaction_furnace" />

**From:** GTNA

**Runs:** Liquefaction Furnace

## What it does

* Main Function: Melts items into fluids using the heat of its coils.
* The recipe's temperature sets the minimum coil tier, like the EBF.
* Attach the stainless-steel extension tower to add Parallel and Accelerate hatches.
