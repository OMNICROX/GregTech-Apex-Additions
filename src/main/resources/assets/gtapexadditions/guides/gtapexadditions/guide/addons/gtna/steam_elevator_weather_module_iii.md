# Steam Weather Module III

<Multiblock id="gtna:steam_elevator_weather_module_iii" />

**From:** GTNA

## What it does

* Controls the weather using steam.
* Adds weather changes module to the Steam Stairway
* Enter a specific material to switch weather, lasting 1 hour per tier
